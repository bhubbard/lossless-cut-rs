How Lossless Surgery Works ⚡

Traditional Video Editors

Decode H.264/HEVC frames ➔ Process in RGB ➔ Re-encode (Loss of quality, 100% CPU heat, takes minutes).

lossless-cut-rs Stream Copy

Parses bitstream packets directly at container level ➔ Copies NAL units at raw NVMe disk speed (Zero re-encode, bit-perfect quality, takes 0.1s).

Installation & Usage 🚀

# Install from Cargo
cargo install --git https://github.com/bhubbard/lossless-cut-rs

# 1. Quick Trim
lossless-cut trim -i input.mp4 -s 00:00:10 -e 00:01:30 -o trimmed.mp4

# 2. Batch Cut from an .llc LosslessCut Project File and Auto-Merge
lossless-cut batch -i full_show.mov -p project.llc -o ./segments --merge

# 3. Extract Audio Losslessly
lossless-cut extract-audio -i conference.mkv -o audio.m4a -t 0

# 4. Merge multiple camera clips
lossless-cut merge -i clip1.mp4 clip2.mp4 clip3.mp4 -o combined.mp4
